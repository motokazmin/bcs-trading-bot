Экспорт для ИИ

Два шага: скопируйте промпт → вставьте в ChatGPT / Claude → прикрепите JSON с данными. Промпт и файл не дублируют друг друга.

Краткий — по метрикам

Сравнение экспериментов, win rate, profit factor. Без списка сделок. Файл: data-summary.json

Подробный — с разбором сделок

Всё из краткого + полный список сделок в experiments[].trades. Файл: data-trades.json

Как использовать

  1. Примените фильтры выше.
  2. Выберите вариант: краткий или подробный.
  3. Нажмите «Копировать промпт» → вставьте в чат ИИ.
  4. Скачайте соответствующий JSON и прикрепите к тому же сообщению.
