# Бриф для поиска новых торговых гипотез (MOEX TQBR)

Документ **только про стратегии и рыночную логику**. Без кода, конфигов и инфраструктуры.

Цель: предложить **новые торговые идеи**, которые можно проверить walk-forward backtest’ом на акциях MOEX (TQBR), с упором на **рост частоты сделок** при сохранении положительного expectancy.

---

## Контекст рынка и ограничений

| Параметр | Значение |
|---|---|
| Рынок | Акции MOEX, класс TQBR |
| Таймфрейм сигналов | M5 (закрытые 5‑минутные свечи) |
| Сессия | 10:00–18:40 MSK, принудительное закрытие к концу дня |
| Депозит в оценке | 200 000 ₽ |
| Риск на сделку | 0,5% депозита |
| Комиссия (модель) | ~0,008% за leg (тариф «Трейдер») |
| Горизонт истории | ~2 года M5 |
| Валидация | Walk-forward (много окон train→test), не один прогон на всей истории |
| Главная метрика | **Expectancy в R** (средний результат сделки в единицах риска), затем profit factor, доля прибыльных окон |
| Не цель | Максимизация PnL на всей истории любой ценой; «красивый» Calmar при минусе в рублях |

**Жёсткие уроки из прошлых прогонов:**

1. **Универс из 9 голубых фишек без фильтра почти всегда убыточен.** Edge появляется только на узком whitelist тикеров под конкретную логику.
2. **Утренний слот и дневной слот — разные режимы.** Одна и та же логика «пробой» утром и после 12:30 ведёт себя по-разному.
3. **Шорты на чистом market-ORB / сыром momentum часто мертвы** на этом universe — long-only и fade/continuation с фильтром работают лучше.
4. **Мало сделок (<30 за 2 года) при высоком expectancy — красный флаг:** риск случайности и overfit, даже если R красивый.
5. **Выбор «лучшего тикера постфактум» из 9 попыток — ловушка multiple comparisons.** Нужна устойчивость по окнам и проверка на другом seed / другом периоде.

## Что уже выбрано как рабочий портфель (champions)

Три независимые по времени логики на одном счёте. Слоты почти не пересекаются.

```
10:00 ──────── 10:30 ──────── 12:30 ──────── 18:40
   │  ORC ✅     │  OR Fade ✅  │  MF Afternoon ✅ │
```

### 1) ORC — Opening Range Continuation (утро)

| | |
|---|---|
| Идея | Строится opening range первых минут → фиксируется **пробой** → вход **не маркетом в момент пробоя**, а **лимитом на ретесте** уровня (continuation) |
| Слот | ~10:00–10:30 MSK |
| Тикеры | MGNT, ROSN, TATN |
| Expectancy | ~+0,49R |
| Profit factor | ~1,6 |
| PnL (оценка, 2 года, 200k) | ~+54k ₽ (~13%/год) |
| Сделок | ~110 за 2 года |
| Статус | **Рабочий champion, заморожен** — не ломать без новой гипотезы |

Почему выжили: ретест режет ложные пробои; узкий whitelist; утренний импульс на выбранных бумагах.

### 2) OR Fade — Opening Range Fade (утро–полдень)

| | |
|---|---|
| Идея | Ложный пробой opening range → **fade** (вход **против** пробоя после возврата / слабости пробоя) |
| Слот | ~10:15–~12:00 MSK |
| Тикеры | LKOH, CHMF, MOEX, AFKS |
| Expectancy | ~+0,50R |
| Profit factor | ~2,0 |
| PnL (оценка, 2 года, 200k) | ~+45k ₽ (~11%/год) |
| Сделок | ~89 за 2 года (раньше было ~34 — уже расширяли частоту через universe) |
| Статус | **Рабочий champion, заморожен** |

Complement к ORC: другой принцип (reversal vs continuation) и другой набор тикеров.

### 3) MF Afternoon — Momentum Filtered (день)

| | |
|---|---|
| Идея | Momentum breakout + фильтр тренда (SMA), **только long**, входы **не раньше ~12:30** |
| Слот | 12:30–18:40 MSK |
| Тикеры | MGNT, TATN |
| Expectancy | ~+0,18R (слабее утренних) |
| Profit factor | ~1,3 |
| PnL (оценка, 2 года, 200k) | ~+12k ₽ (~3%/год) |
| Сделок | ~67 за 2 года |
| Статус | **Рабочий champion, заморожен** (слабое звено по доходу и частоте) |

## Портфель в целом — где болит

| Метрика | Оценка baseline |
|---|---|
| Суммарный PnL (~2 года) | ~+110k ₽ на 200k (~27%/год простой annualization) |
| Средний expectancy | ~+0,42R |
| Всего сделок | ~266 за ~2 года ≈ **~11 сделок/мес ≈ 2–3 сделки/неделя** |
| Практика / ориентир пользователя | Профит есть, но частота низкая (**порядка единиц сделок в неделю**) — нужно копать в сторону **увеличения числа сделок** без убийства expectancy |

**Главный bottleneck:** не отсутствие edge у ORC/OR Fade, а **редкость сигналов**. ORC даёт львиную долю PnL; OR Fade и MF — хороший R, но мало сделок. Для роста доходности портфеля приоритет — **частота при сохранении exp_R > ~+0,15…+0,25**.

## Что пробовали и отвергли

Не предлагать «ещё раз то же самое» без **новой** гипотезы (другой принцип, слот, фильтр или universe).

| Линия | Суть | Почему отвергли |
|---|---|---|
| Сырой **momentum breakout** на 9 тикерах | Пробой high/low lookback, market-style вход | Нет edge; expectancy отрицательный / около нуля |
| Momentum breakout lean (SBER/ROSN/NVTK) | Тот же принцип, узкий universe | Backtest не подтвердил устойчивый плюс |
| Momentum breakout GAZP+CHMF | Узкий universe | Слишком слабый плюс (~+0,05R) — не champion |
| Momentum breakout afternoon (GAZP+CHMF) | Дневной слот | Отрицательный / околонулевой expectancy |
| Классический **opening range breakout (market)** | Вход маркетом сразу на пробое OR | Хуже ORC; шорты почти мертвы; убыток на walk-forward |
| **Mean reversion** (fade от SMA) на широком universe | Контртренд от отклонения | Убыток без жёсткого whitelist |
| Mean reversion afternoon (MGNT/ROSN/TATN) | Тот же принцип днём | ~0 expectancy — отклонено |
| Momentum filtered **без** afternoon delay и без whitelist | Фильтры «в среднем» | Убыток на matrix |
| ORC на всех 9 тикерах | Continuation без фильтра | Катастрофический минус — whitelist критичен |
| ORC + SBER | Добавление SBER к утреннему continuation | Стабильно портит результат — SBER исключён |
| Переоптимизация «score/Calmar» без expectancy | Поиск по одной метрике | Высокий score при минусе в ₽; ложные чемпионы |

**Паттерн отказов:** широкий universe, вход «в момент пробоя» без ретеста/подтверждения, шорты без edge, дневной mean-reversion на голубых фишках, оптимизация под шум.

## Что уже доказало ценность (паттерны успеха)

Использовать как **строительные блоки** новых идей, а не копировать один в один:

1. **Opening Range как якорь** — утренний диапазон информативен; важна *реакция* на него (ретест / ложный пробой), а не сам факт касания.
2. **Ретест лучше chase** — continuation на возврате к уровню переживает ложные пробои лучше, чем market-вход в импульс.
3. **Fade ложного пробоя** — отдельный прибыльный режим на другом whitelist (нефть/металлы/биржа/финансовый слой: LKOH, CHMF, MOEX, AFKS).
4. **Разделение слотов** — утро ≠ день; одна стратегия на весь день обычно хуже двух специализированных.
5. **Long-only днём** для momentum — шорты в afternoon-momentum не окупились.
6. **Per-ticker edge** — MGNT часто сильный; SBER вреден для ORC, полезнее смотреть в MF/других логиках отдельно.
7. **Мало параметров «магии»** — рабочие конфиги простые: OR-минуты, порог пробоя, ATR-стоп, RR ~1,2–1,8, ограниченный trail, 1–2 входа в день на тикер.

## Запрос к следующей итерации исследований

Нужны **новые гипотезы стратегий** (или сильные вариации), ориентированные на:

### Приоритет A — увеличить частоту сделок

Целевое мышление (порядок величин, не KPI-контракт):

- сейчас портфель ≈ **2–3 сделки/неделя** (оценка по ~11/мес);
- желательно выйти к **~5+ сделкам/неделя** суммарно по портфелю **или** добавить слот/логику, которая даёт **сопоставимый expectancy** при заметно большем числе сделок;
- при этом **не** жертвовать ниже порога: expectancy ≳ **+0,15R**, profit factor ≳ **1,3**, устойчивость по walk-forward окнам.

Где копать в первую очередь (из внутренней приоритизации):

1. **OR Fade — ещё частота** (уже расширяли universe; можно искать соседние режимы: другой OR, более мягкий fade, второй вход, соседние тикеры — но не «вернуть SBER в ORC»).
2. **MF Afternoon — расширение whitelist** (есть сигналы, что SBER/NVTK/ROSN в solo-matrix выглядели живыми — нужна гипотеза *почему* и проверка без multiple-comparisons самообмана).
3. **Новый слот / новый принцип**, который не дублирует ORC/Fade/MF (иначе конкуренция за те же сделки).

### Приоритет B — не ломать champions

- ORC / OR Fade / MF Afternoon считать **замороженным baseline**.
- Новые идеи — **дополнение** (новый слот, другой принцип, другой universe), а не «перетюнить ORC на 10%».
- Не возвращаться к отклонённым линиям без явной новой механики.

### Приоритет C — реалистичность для акций TQBR

Учитывать:

- комиссия и редкие сделки съедают edge при скальпе;
- EOD-закрытие — нельзя держать через ночь в текущей модели;
- ликвидность голубых фишек: HFT/маркет-мейкеры на чистом M5-пробое — слабое место сырых breakout;
- одновременная позиция на одном тикере (MGNT/TATN уже заняты утром ORC и днём MF).

## Формат желаемых предложений

Для каждой идеи опиши:

1. **Название и принцип** (1–2 предложения, рыночная логика).
2. **Слот времени** (MSK) и почему он не конфликтует с ORC / OR Fade / MF.
3. **Universe** — какие типы бумаг и почему (не «все 9»).
4. **Условия входа** (что должно произойти на M5; long/short/оба).
5. **Условия выхода** (идея стопа/тейка/трейла на уровне логики, без API).
6. **Откуда возьмутся дополнительные сделки** (почему частота выше, чем у текущего портфеля).
7. **Риски / как убьёт edge** (что проверить первым на walk-forward).
8. **Почему это не повтор отклонённых линий** из таблицы выше.

Предпочтительны **3–7 конкретных гипотез**, отсортированных по ожидаемому вкладу в частоту × качество, а не длинный список общих советов («добавить объём», «использовать RSI») без торгового сценария.

## Запрещённые / слабые предложения (если без новой механики)

- Ещё один grid по lookback/ATR на сыром momentum breakout на 9 тикерах.
- Market-ORB «как у всех» без ретеста/fade-логики.
- Mean reversion от SMA на всём дне без нового фильтра режима.
- «Возьмём все тикеры, где solo-matrix был плюс» без общей гипотезы.
- Увеличение `max entries` / сужение стопа **как единственная** идея — это тюнинг, не стратегия.
- Перенос тех же правил ORC на другие таймфреймы без объяснения, откуда частота и почему edge сохранится.

| Тикер | Наблюдение |
