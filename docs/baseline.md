# Baseline портфеля

Эталон для сравнения paper/live с backtest на **едином счёте** 200 000 ₽.

```bash
go run ./cmd/optimizer portfolio-backtest \
  -config configs/runs/portfolio-paper.yaml \
  -date-from 2024-07-04 -date-to 2026-08-08
```

Модель: M5 CSV, комиссия 0,008%/leg, **проскальзывание 1 б.п. на ногу**
(`costs.slippage_bps`), same-bar exit после ORC limit-fill, гейт входа `tradeaudit.Rejects()`.

Обновлено **2026-08-30** после фикса модели исполнения входа
([`analysis/0001`](analysis/0001-entry-fill-adverse-selection.md)).

> слот `orc-complement` добавили позже и baseline не переснимали. Числа ниже — с текущим

### Оговорки

- Параметры чемпионов всё ещё подобраны оптимизатором на **старой** модели фила.
  Числа выше получены на неоптимальных параметрах; переоптимизация ещё не делалась.
- Backtest систематически оптимистичнее live. На окне 2026-08-10 → 2026-08-28 он давал
  +0,236R, тогда как live отработал −0,45R. Гейт входа теперь общий для обоих путей,
  но насколько сократился разрыв — покажет только новый virtual-прогон.
- **Тики против M5.** Live считает выход по каждому тику, backtest — по 4 точкам на бар.
  Стресс-тест `-intrabar-oscillations 2..3` (повторный проход по экстремумам свечи)
  даёт +0,551R против +0,560R, то есть −1,6%; при n=3 результат не меняется вовсе.
  Причина геометрическая: медианный диапазон свечи M5 ≈ 18,5 б.п., а R после
  `min_stop_bps: 20` — от 20 б.п. Непрерывный трейлинг срабатывает на откате в 1R
  от пика, и такой размах редко умещается внутри одной свечи. Реальные тики не выходят
  за high/low своего бара, поэтому этот тест — верхняя граница внутрибарного риска.
- Проскальзывание применяется к **обеим ногам**. Для стратегий со входом лимитом
  на уровне (ORC) вход так оценивается с запасом: лимитная заявка не проскальзывает,
  она либо исполняется по своей цене, либо нет. То есть правая колонка — оценка снизу.

## Что сравнивать в paper / live

| Метрика | Ориентир |
|---------|----------|
| `expectancy_r` | **~+0,44R** в backtest с издержками; в live ожидать меньше |
| Net PnL / мес на 200k | ориентир по shared backtest, не гарантированный live |
| Win rate | ~60–63% в backtest |
| Profit factor | > 1,3 (shared backtest ~2,1) |
| Circuit Breaker | 2% = −4 000 ₽/день max |

**Красные флаги:** exp_R < 0 два месяца подряд; PF < 1,0 на 30+ сделках; просадка > 10% депозита без восстановления.

После смены params champions, комиссии или модели fill — пересчитать через `portfolio-backtest`. Описание слотов: [`portfolio.md`](portfolio.md).
