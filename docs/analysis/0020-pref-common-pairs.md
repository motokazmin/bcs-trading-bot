# 0020 — Пары «обыкновенная / привилегированная» внутри дня: регистрация до прогона

Записано и закоммичено **до** первого расчёта доходности любого правила.

## Зачем

После 0008–0018 направленного хода у отдельной бумаги не нашлось ни на M5, ни на дневках.
Пара «обычка / преф» одной компании — другой источник: спред между бумагами держится
экономикой (одна компания, близкие права на дивиденд), а отклоняется потоком заявок.
Позиция нейтральна к рынку и к новостям по компании — то, на чём спотыкались прошлые опыты.

## Что уже видено до регистрации (`scripts/pairs/describe.py`)

Описательный разбор свойств спреда `s = ln(преф / обычка)`, доходность правил **не считалась**.
Но выбор пар и горизонта им определён — это надо держать в уме при оценке.

- **На горизонте лет спред — режим, а не константа**: дисконт SBERP −31% (2014) → 0 (2023+),
  премия SNGSP +12% → +81%. Двигают дивидендные политики. Ставить на возврат к долгому среднему нельзя.
- **Ночные скачки спреда ≥ 2% — в основном дивидендные отсечки** (SNGSP каждый июль −8…−12%).
- **Внутри дня возврат к якорю сильный**: отношение дисперсий за 6.5 ч VR = 0.18 (SBER),
  0.28 (RTKM), 0.34 (MTLR), 0.22 → 0.54 (TATN, 2023–24 → 2025–26 — **ослабление на хвосте
  уже видено**), 0.72 (SNGS). Отскок бид/аск дал бы падение VR только на втором шаге.
- **Размах против издержек**: медиана |отклонения| 6 б.п. у SBER, 16 TATN, 30 RTKM, 41 MTLR,
  48 SNGS; у префов широкий спред бид/аск. Окупаться могут только хвосты.
- **Неторгованная нога**: у RTKMP 31% баров без изменения close — ложные отклонения.

## Данные

M5 БКС, `data/pairs/` (`sync-history -output-dir data/pairs -initial-years 4`), 2022-10-05 → 2026-09-30.
Основная сессия 10:00–18:40, будни, бары, где есть обе ноги.

**Пары:** TATN/TATNP, RTKM/RTKMP, MTLR/MTLRP, SNGS/SNGSP — основной набор.
SBER/SBERP — **контроль**: отклонения меньше издержек, ожидаю ≤ 0; в критерий не входит.
BANE/BANEP исключена: оборот обычки 44 млн ₽/день.

## Правило

На закрытии бара `t` (обе ноги с `volume > 0` в этом баре):

- **якорь** `a_t` — среднее `s` по предыдущим ≤ `N` барам **сегодняшнего дня** (не через ночь —
  иначе дивидендная отсечка даёт ложное отклонение на открытии); нужно ≥ 6 баров, то есть
  сигналов нет до 10:30;
- **отклонение** `d_t = s_t − a_t`, б.п.;
- **вход**, если позиции нет и `|d_t| ≥ k · C` (`C` — издержки круга пары, ниже): `d > 0` —
  преф дорог, шорт префа и лонг обычки на равные рубли; `d < 0` — наоборот;
- **выход**, если `d_u` пересёк ноль (якорь пересчитывается каждый бар) — по open бара `u+1`;
- **EOD**: close бара, кончающегося в 18:40; новых входов с бара, начинающегося в 18:00 и позже;
- **исполнение**: вход и выход — open следующего бара **по обеим ногам**, не close сигнального бара;
- одна позиция на пару; после выхода можно войти снова; стопа нет — риск ограничен EOD.

**Сетка подбора** (9 наборов, общий для всех пар): `N ∈ {12, 24, 48}`, `k ∈ {1.5, 2, 3}`.

## Издержки

На ногу: комиссия 0.8 б.п. + проскальзывание = **половина спреда Ролла** по M5 на периоде
подбора, не меньше 1 б.п. Посчитано до прогона:

| бумага | Ролл | на ногу | | бумага | Ролл | на ногу |
|---|---:|---:|---|---|---:|---:|
| TATN | 6.6 | 3.3 | | TATNP | 5.8 | 2.9 |
| RTKM | 8.1 | 4.0 | | RTKMP | 12.6 | 6.3 |
| MTLR | 10.1 | 5.0 | | MTLRP | 12.2 | 6.1 |
| SNGS | 9.2 | 4.6 | | SNGSP | 7.0 | 3.5 |
| SBER | 4.9 | 2.4 | | SBERP | 4.9 | 2.4 |

Круг пары `C = 2·(slip_c + slip_p) + 4·0.8`: TATN 15.6, RTKM 23.8, MTLR 25.4, SNGS 19.4, SBER 12.8 б.п.
Ролл на M5 у ликвидных бумаг завышает реальный спред (SBER — доли б.п. в стакане): оценка консервативна.

**Шорт внутри дня** — без платы за перенос (позиция закрывается до вечера).

## Подбор и хвост

- **Подбор:** 2022-10-05 → 2025-03-31. Набор `(N, k)` — по t-статистике среднего чистого
  результата сделки, пул четырёх пар, SE кластеризована по дню; ≥ 100 сделок.
- **Хвост:** 2025-04-01 → 2026-09-30, **один прогон** выбранного набора.

Результат сделки — `pnl / N₁` в б.п., где `N₁` — рубли на одну ногу.

## Критерий (на хвосте, всё одновременно)

1. средний чистый результат сделки по пулу > 0 с **t ≥ 2** (SE по дню);
2. **≥ 3 из 4** пар основного набора в плюсе;
3. при проскальзывании **× 1.5** пул остаётся > 0.

Иначе — преимущества нет.

## Диагностика (не критерий)

- вход по close сигнального бара вместо open следующего — сколько «дохода» даёт отскок бид/аск;
- проскальзывание 1 б.п. — оптимистичная граница;
- доходность на капитал: капитал пары = 2·`N₁`, годовая в % и сравнение со ставкой денежного рынка.
  Стратегия внутридневная: ночью капитал может лежать в фонде денежного рынка, так что результат
  стратегии — **добавка** к нему, а не альтернатива;
- ёмкость: доля `N₁` в медианном обороте менее ликвидной ноги.

## Чего не даёт

- OHLC M5 не стакан: open следующего бара не гарантирует фил обеих ног по этой цене одновременно.
  Риск «ноги» (одна исполнилась, другая ушла) не моделируется — его заменяет консервативный Ролл.
- Разбор свойств спреда видел весь период, включая хвост; ослабление TATN на хвосте уже известно.
- Четыре пары — малая выборка компаний; плюс может держаться на одной.
- Для торговли бот должен уметь пару: две ноги одновременно, одна в шорт. Сейчас не умеет.
