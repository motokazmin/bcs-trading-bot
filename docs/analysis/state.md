**До фикса стратегии в live решали по формирующейся свече** — первому WS-обновлению

**Фикс:** фид отдаёт стратегиям только закрытые бары. После деплоя — архивировать
сделки до него и начинать выборку заново; первая проверка — поштучная сверка недели
live с `portfolio-backtest` за тот же период. [0004](0004-live-decides-on-forming-bar.md)

**3. Переоптимизация оставшихся 4 слотов — ПОСЛЕ подтверждения механики.**
Заготовки готовы: `configs/strategies/exit-*.yaml` (переподбор выхода, вход

- **Оставшиеся 4 слота: пространства поиска готовы, подбор НЕ запускался.**
  `configs/strategies/exit-*.yaml` — переподбор выхода с зафиксированным входом,
  `trailActivationR` долей от тейка. Пробный прогон `orc-wave2` дал `best_score=-Inf`:
  ни один trial не набрал `-min-trades 20` на двухмесячных окнах — слот торгует три
  тикера в узком окне. Для таких слотов нужен больший `-window-months` либо
  сниженный `-min-trades`, иначе подбор вырождается в пустоту.

- **Слоты связаны через общий счёт, оценивать только портфельно.** Правка одного
  меняет других: кандидат, трогавший только `or-fade`, сдвинул `orc-complement`
  с 203 сделок на 196; правка только `orc-complement` уронила прибыль `or-fade`
  2744 → 2129 ₽ при тех же 62 сделках. Оптимизатор портфельной конкуренции не видит
  вовсе — он считает слот в одиночку. Отсюда портфельные пункты в критерии приёмки.

- **Взаимодействие «вход × выход» не проверено.** Вход и выход подбирались по
  отдельности, при фиксированном партнёре. Возможно, при новом выходе оптимален
  другой вход — уточняющий проход по входу следующий кандидат.

- **`or-fade-conservative` деградирует независимо от параметров:** старый чемпион
  +0.240 на 2024-07→2026-03 и +0.096 на 2026-04→2026-09. Переподбором не лечится;
  кандидат на вывод из портфеля — решать по live.
