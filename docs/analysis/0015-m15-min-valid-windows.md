# 0015 — Поиск чемпионов на M15 с планкой по окнам: регистрация до прогона

Записано и закоммичено **до** подбора. Повтор [0014](0014-m15-champion-search.md) с одним
изменением — правилом оценки trial.

## Что меняется и почему

В 0014 оценка trial — медиана Calmar по окнам, где сделок ≥ `-min-trades`; остальные окна
не считаются. Так задумано с первого коммита оптимизатора, но у правила лазейка: у лучших
наборов M15 в оценку вошло 1–6 окон из 16, и оптимизатор выбирал редкие наборы по одному-двум
удачным окнам.

Новое правило (`core.WindowScore`, флаг `optimizer run -min-valid-windows`, по умолчанию 0.75):
если сделок ≥ `-min-trades` меньше чем в **75% окон**, trial получает −Inf. Иначе — как раньше,
медиана Calmar по прошедшим окнам. `-min-valid-windows 0` воспроизводит прежнее правило.

## Всё остальное — как в 0014, без изменений

- те же пять пространств `configs/strategies/m15/*.yaml`, файлы не правились;
- те же 10 тикеров, `data/history-m15`;
- подбор 2024-10-04 → 2026-03-31; 300 trials, seed 1, окна 2 мес шагом 1, `-min-trades 10`;
- оценка — `scripts/m15-evaluate.py`, однослотовый `portfolio-backtest`;
- критерий на хвосте 2026-04-01 → 2026-10-02: сделок ≥ 30, `exp_R` > 0 при 2 б.п.,
  `exp_R` при 1 б.п. ≥ половины `exp_R` подбора (а тот > 0).

## Хвост — второй взгляд

Хвост уже открывался в 0014. Параметры по нему не правились, но правило оценки изменено
после того, как результат был виден, и решение о повторе принято по нему же. Поэтому:

- прошедший критерий — **кандидат на paper**, доказательность ниже, чем у первого прогона;
- для вывода «на M15 преимущества нет» отрицательный результат здесь годится, для
  «есть» — нет: нужен paper или полгода новых данных.

## Чего не даёт

Как в 0014: поправки на множественность нет (пять стратегий на одном хвосте), контрольного
переподбора M5 нет, кандидат ≠ чемпион, live на M15 не запускался.

Возможный исход, записанный заранее: при планке 0.75 часть стратегий не наберёт ни одного
допустимого trial (на M15 мало сигналов). Это ответ «при таких частотах стратегия на M15
не судима на двухмесячных окнах», а не повод снижать планку после прогона.
