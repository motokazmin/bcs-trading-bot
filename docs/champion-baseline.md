# Baseline доходности champions (для сравнения с live)

**Зачем:** эталонные метрики walk-forward backtest после commission-rerun (2026-07-11). Сверяйте paper и real с этими цифрами.

**Источник:** `results/*/runs-registry.json`, прогоны `*-rerun`, seed 1. Инструменты: **акции TQBR** (MOEX). Комиссия: **0,008% за leg** (BCS «Трейдер»). Депозит в backtest: **200 000 ₽**, риск **0,5%** на сделку.

**Ограничения модели:** fill по **close** свечи, **без проскальзывания**; лимит на вход в live не моделируется. Портфельная сумма — **оценка** (три отдельных backtest'а на одном депозите, слоты по времени не пересекаются).

## По стратегиям

Backtest на депозите **200 000 ₽**, риск **0,5%** на сделку. Каждый слот — **отдельный** прогон на полном депозите (не portfolio-sim).

## Портфель (3 champions)

### A. Сумма solo (оценка, без единого счёта)

Каждый слот — **отдельный** walk-forward backtest на полном депозите 200k. Слоты по времени почти не пересекаются; конкуренция за капитал/тикер **не** моделируется.

| Метрика | Baseline |
|---------|----------|
| Суммарный net PnL (~2 года) | **+110 047 ₽** |
| Доходность на 200k (~2 года) | **~55,0%** |
| Годовая (простая annualization) | **~27,5% / год** |
| Сделок всего | **266** (~133 / год, ~0,5 / торг. день) |
| Средневзвешенный exp_R | **+0,42R** |
| Средний PnL на сделку | **~414 ₽** |
| Средний PnL в месяц | **~4 585 ₽** (~2,3% от депозита) |

Формула exp_R портфеля: `(0,49×110 + 0,50×89 + 0,18×67) / 266 ≈ +0,42R`.

## Что сравнивать в paper / live

| Метрика | Где смотреть | Baseline (ориентир) |
|---------|--------------|---------------------|
| `expectancy_r` | admin / export | **+0,59R** (§ C); ранее 3 champions +0,53R (§ B) |
| Net PnL в ₽ | `data/trades.db`, admin | ~+11,5k ₽/мес на 200k (shared +276k / 24) |
| Net PnL по слоту | admin / export | см. таблицу C |
| Win rate | admin | ~55–60% |
| Profit factor | admin / export | > 1,3 (shared ~2,0) |
| Сделок в месяц | admin | ~20 (473 / 24 мес) |
| Просадка / серия стопов | логи, CB | CB 2% = −4 000 ₽/день max |
| ticker busy | логи | редкий skip пересекающихся тикеров |

**Красные флаги:** exp_R < 0 два месяца подряд; PF < 1,0 на 30+ сделках; просадка > 10% от депозита без восстановления.
